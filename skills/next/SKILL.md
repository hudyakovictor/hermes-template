# /next — следующее действие

```bash
python tools/rg.py next
python tools/rg.py status
```

Ответ всегда трёхчастный и короткий:

1. **Кто** — `H-XXX`, его PPI и корзина.
2. **Почему он** — лучшая ценность за GPU-час, а не «самая интересная».
3. **Одна команда** — ровно одна строка, которую надо выполнить.

Если NEXT нет — назови причину из списка: очередь пуста (нужен `/dr`), все гипотезы
ждут вердикта (`/v`), пауза (`/resume`), нет VRAM (`/gpu`), ждёт подтверждения
(`/approve`), исчерпан суточный бюджет (ждём следующих суток).

Никогда не отвечай «работаю над этим» без конкретного ID и команды.
