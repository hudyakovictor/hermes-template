# /doctor — самопроверка

```bash
python tools/selfcheck.py all
```

Запускать: после установки, после обновления профиля, перед включением автономии
и каждый раз, когда что-то «непонятно не работает».

## Как читать результат

- ✅ OK — проверка прошла.
- ⚠️ WARN — работать можно, но часть функций деградирует (например, в белом списке
  один пользователь вместо двух, или модели нет в списке Ollama).
- ❌ FAIL — автономию включать нельзя. Выходной код 1.

## Самая важная проверка — изоляция

`check_isolation` ищет тот же Telegram-токен в других профилях (`$HERMES_HOME/profiles/*/.env`
и корневом `.env`). Если токен совпадает с токеном первого агента — второй
gateway не запустится (сработает блокировка токена), или два процесса будут
воровать апдейты друг у друга. Лечение одно: отдельный бот в BotFather.

## Если падает модель

Проверь: `ollama list`, затем доступность `RESEARCHAGEN_MODEL_BASE_URL`.
Типовая ошибка — адрес без `/v1` или Ollama, слушающая только `127.0.0.1`,
когда обращаются по имени хоста.

На macOS отсутствие NVIDIA GPU — не ошибка: режим отладки, прогоны идут dry-run.
