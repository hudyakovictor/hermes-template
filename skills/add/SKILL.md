# /add — лид от человека

```bash
python tools/inbox.py add "текст идеи" --from <user_id>
python tools/inbox.py list
```

## Правила обращения с идеями людей

Идея человека — это **источник лидов, а не приказ**. Она:

1. НЕ прерывает идущий эксперимент и не получает автоматический приоритет.
2. Проходит тот же гейт из 8 проверок, что и собственные гипотезы агента.
3. При продвижении помечается `source=inbox:IN-XXX`, чтобы потом было видно,
   какое качество у идей из разных источников.

```bash
python tools/inbox.py take IN-001 --title "..." --signals 3 --hours 4 --forecast 10
python tools/inbox.py drop IN-001 --why "Уже опубликовано в <ссылка>, новизны нет"
```

Отказ всегда с причиной и всегда вслух в Telegram. Молчаливое игнорирование
идей — самый быстрый способ потерять доверие к автономному агенту.

Если идея хорошая, но вне `FOCUS.md` — скажи об этом прямо и не бери в работу:
смена фокуса — решение человека, а не следствие одного сообщения.
