# /pool — очередь и приоритеты

```bash
python tools/queue.py list
python tools/queue.py next
python tools/queue.py stats
```

## Как читать цифры

**PI** — ценность гипотезы (0–1) как взвешенная сумма шести факторов:
число независимых сигналов, новизна, ранность проявления (чем раньше процент бюджета
обучения — тем лучше), шанс стать стандартом, денежный эффект, решаемость на
одной RTX 5090.

**PPI = PI / оценка в GPU-часах** — ценность за час. Главный критерий, потому что у нас
один GPU, а не кластер. Гипотеза PI 0.9 на 40 ч хуже, чем PI 0.6 на 3 ч.

**Корзины:** P1 ≤ 4 ч, P2 ≤ 12 ч, P3 ≤ 48 ч, P4 > 48 ч.
**NEXT** = лучший PPI в P1–P2; если там пусто — лучший PI с учётом старения.
**Старение** — +0.05 PI за сутки ожидания, но не больше +0.30: так медленные
гипотезы не голодают вечно, но и не пролезают вперед без оснований.

## Что сказать человеку

Не пересказывай таблицу словами. Скажи: кто NEXT, почему именно он, что его блокирует
(гейт? VRAM? бюджет? подтверждение?) и какое одно действие сдвинет дело.

Если живых гипотез меньше минимума из конфига — приоритет не запуск, а `/dr`:
пустая очередь означает, что агент перестал быть исследователем и стал исполнителем.
