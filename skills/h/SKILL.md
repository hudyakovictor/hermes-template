# /h — карточка гипотезы

```bash
python tools/hypo.py card H-XXX      # показать
python tools/hypo.py check H-XXX     # гейт
python tools/hypo.py new "..." --signals 3 --hours 4 --forecast 12
```

## Обязательные секции и смысл каждой

| Секция | Зачем она там |
|---|---|
| `signal_chain` | ≥ 3 независимых сигнала со ссылками. Один сигнал — это совпадение |
| `mechanism` | Физическая причина, а не корреляция. Корреляция без механизма не патентуется |
| `why_missed` | Почему отрасль этого не сделала. Нет ответа — скорее всего сделала |
| `minimal_test` | Самый дешёвый опыт, способный УБИТЬ гипотезу |
| `pass_fail` | Числовой критерий ДО запуска |
| `scale_path` | Путь от игрушки до реального обучения |
| `impact` | Сколько compute экономится и кому это выгодно |
| `falsification` | Что именно обязано случиться, чтобы гипотеза считалась ложной |
| `kill_checks` | 8 проверок, каждая с `passed: true/false` и обоснованием |
| `forecast` | Число ДО эксперимента. Менять потом — запрещено |

## 8 kill-проверок

1. Это уже опубликовано — искал ли я три разные формулировки?
2. Сигналы не независимы — одна лаборатория, один датасет, одна пересказанная работа?
3. Механизм — пересказ корреляции другими словами?
4. Эффект объясняется банальностью: LR, warmup, batch size, сид, регуляризация?
5. Измерение шумнее ожидаемого эффекта на доступном числе seeds?
6. На одной RTX 5090 вопрос в принципе нерешаем?
7. Даже при подтверждении ничего не меняется в практике?

Любое «да» — снятие гипотезы через `/kill`, а не попытка её спасти переформулировкой.
