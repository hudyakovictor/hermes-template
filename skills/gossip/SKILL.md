# /gossip — подслушать Курилку

Показывает последние реплики команды из `state/researchagen.sqlite3` (таблица
`crew_chat`). Это развлекательная телеметрия: она не влияет на очередь, вердикты
и GPU. Числа в вердиктах остаются сухими — шутки живут только здесь.

```bash
python tools/rg.py gossip --n 30      # последние 30 реплик
python tools/rg.py crew stats         # бюджет Курилки, споры, нуджи, AGI-часы
```

## Что здесь можно увидеть

- **Сцены событий**: запуск, финиш, вердикт, kill-stage, вытеснение — каждый
  шаг контура команда комментирует в жанре «панк-таблоид + корпоративный
  некролог + сухой стендап».
- **Споры** ⚔️: «проверка на прочность» — атака, защита и арбитраж Шефа с
  реальными числами (kill-checks, прогноз, отклонение).
- **Нуджи**: заранее продуманные «умные фразы» с приорами эффективности
  95%/90%, которые рандомно вставляются в разговор.
- **AGI-часы**: сколько дней осталось до прихода AGI и почему заказчик к этому
  времени уже будет работать на заводе. Чёрный юмор по регламенту.

## Правила жанра (для модели)

1. Сатира над заказчиком — жанр, а не оценка: заказчик в Курилке — «наивный
   мечтатель с кнопкой БАБЛО», но его идеи проходят тот же конвейер, что и наши.
2. Стажёра не обижать по-настоящему: его наивность — учебное пособие.
3. Никакой лжи в числах: шутить можно только о том, что уже зафиксировано в
   базе (прогноз, факт, отклонение, GPU-часы).
4. Не путать Курилку с отчётами: вердикты, дайджесты и статусы — сухие.
