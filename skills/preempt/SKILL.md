# /preempt — вытеснение и пауза

```bash
python tools/dispatch.py preempt          # проверить и вытеснить при основаниях
python tools/dispatch.py pause            # стоп автозапусков
python tools/dispatch.py resume
```

## Когда вытеснение разрешено

Только если PPI претендента ≥ `preempt_ratio` × PPI текущего (по умолчанию ×1.5).
Мелкое превосходство не стоит потери прогрева и частичных результатов.

## Как именно останавливаем

Пишется флаг `state/stop-<H-ID>.flag`. Раннер видит его между seeds, дописывает
`summary.json` и выходит сам. **Никогда не убивать процесс сигналом**: потерянные
на полпути метрики невосстановимы, а частичные seeds всё ещё имеют ценность.

Вытесненный прогон получает состояние `preempted`, гипотеза возвращается в очередь
без потери места и без вердикта. Вердикт по неполным данным запрещён.

## Пауза

`pause` НЕ останавливает текущий прогон — он только запрещает новые запуски.
Так человек может освободить GPU под свои задачи, не теряя уже считанное.
В паузе дайджест обязан говорить об этом первой строкой.
