# /idea — идея через бота

```bash
python tools/rg.py idea "текст идеи"            # принять в разбор (+обсуждение)
python tools/rg.py triage IN-001 --signals 3 --forecast 12 --hours 2   # разбор
python tools/rg.py ideas                        # очередь идей и лог отклонённых
```

## Поток (таймлайн)

1. **Приём**: идея санируется, дубли проверяются СРАЗУ против лога идей и
   всех гипотез. Дубль отклонённой идеи → «это уже рассматривали (причина)»
   автоматически, без разбора.
2. **Обсуждение**: экипаж обсуждает идею в aichat с цифрами — предварительная
   оценка по тексту (ссылки, покупатель, метрика) или оценка агента на
   `/triage` (флаги перекрывают предварительную).
3. **Решение по порогам** (не по вкусу): сигналов ≥ 3 и перспективность
   PI ≥ 0.40 → очередь (карточка гипотезы + ставки агентов); иначе —
   в лог неэффективных с причиной.
4. **Память о дублях**: каждая отклонённая идея остаётся в логе; новая
   похожая идея или гипотеза получает ранний отказ с причиной и ссылкой.

## Правила

- Отказ всегда с причиной и вслух; молчаливых отказов нет.
- Идея человека — сырьё: приоритет она получает только через те же пороги,
  что и гипотезы агента (R5).
- «Уже рассматривали» — не приговор: новые данные (новый покупатель, новый
  источник) позволяют поднять идею заново через `hypo new --force`.
