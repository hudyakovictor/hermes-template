# /panel — панель управления

```bash
python tools/report.py status
python tools/tg.py send "$(python tools/report.py status --text)"
```

Панель — не отдельный бот-процесс. Управление идёт через штатный Telegram-gateway
самого Hermes (`researchagen gateway start`), потому что второй процесс с тем же
токеном убивает long-polling у обоих. Сообщения телеметрии отправляются
через Bot API напрямую из `tools/tg.py` — это отправка, а не приём, конфликта нет.

## Структура тем в чате

| Тема | Содержание |
|---|---|
| Штаб | статус, дайджесты, недельные отчёты |
| Conclave | короткие реплики персонажей и текущая review-комната |
| Дебаты | критика, steelman, rebuttal и решение Шефа |
| Заказчик | редкие параллельные комментарии о задаче и человеке |
| Прогоны | старт/финиш/вытеснение, прогресс seeds |
| Вердикты | закрытые гипотезы, отклонения прогнозов |
| Лиды | `/add` от обоих пользователей |

## Команды бота (меню BotFather)

```
status — что сейчас идёт, что дальше
pool — очередь гипотез с PI/PPI
next — кто следующий и почему
launch — запустить эксперимент
approve — разрешить дорогой прогон
pause — остановить автозапуски
resume — вернуть автономию
v — вердикт по гипотезе
add — отдать агенту свою идею
digest — сводка за сутки
gpu — VRAM и бюджет
doctor — самопроверка
conclave — transcript комнаты персонажей
```

## Два пользователя — одна картина мира

Оба ID перечислены в `TELEGRAM_ALLOWED_USERS`, оба пишут в один чат, всё состояние
живёт в одной SQLite. Поэтому любое действие одного видно другому без
синхронизации. В ответах всегда указывай автора действия, если оно меняет
планы: «пауза поставлена пользователем 12345».
