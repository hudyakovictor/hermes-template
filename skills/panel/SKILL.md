# /panel — панель управления

```bash
python tools/rg.py panel            # собрать и показать
python tools/rg.py panel --send     # отправить в топик «Штаб»
```

Панель — это не отдельный бот-процесс. Управление идёт через штатный
Telegram-gateway самого Hermes (`researchagen gateway start`), потому что
второй процесс на тот же токен убивает long-polling у обоих. Отправка
телеметрии — Bot API из `tools/tg.py` (отправка, не приём — конфликта нет).
Панель собрана в `tools/report.py :: panel` из единой SQLite, поэтому оба
пользователя всегда видят одни и те же цифры.

## Семь стадий на одном экране

1. **Сырьё** — новые лиды в inbox и число сигналов;
2. **Очередь** — живые гипотезы, топ по PPI, кто на чекпойнте;
3. **Прогон** — что идёт на GPU сейчас и сколько уже;
4. **Вердикты** — счёт вердиктов, MAE прогнозов, hit-rate;
5. **Ревью** — открытые замечания взаимного ревью экипажа;
6. **aichat** — объём переписки, доля «шёпота», мьют;
7. **Ресурсы** — свободная VRAM, суточный бюджет, автозапуск.

## Пульт вмешательства

Автономия — по умолчанию; вмешиваться можно в любой момент:

| Команда | Что делает |
|---|---|
| `/pause` `/resume` | стоп/старт автозапусков экспериментов |
| `/launch H-XXX` | запуск уровня вручную |
| `/approve H-XXX` | разрешение дорогого прогона (> лимита GPU-ч) |
| `/v H-XXX` | закрыть гипотезу вердиктом (факт против прогноза) |
| `/kill H-XXX` | снять гипотезу до GPU (успех по регламенту) |
| `/add` | идея человека в inbox — через общий конвейер PI |
| `/aichat` | переписка экипажа: споры, ревью, «шёпот» |
| `python tools/rg.py crew mute 2h` | мьют доставок чата (без правки конфига) |
| `python tools/rg.py crew review` | прогнать взаимное ревью сейчас |
| `/doctor` | самопроверка контура |

Главный агент (parent Hermes) остаётся начальником контура: диспетчер и
governor работают кодом по cron, research-тики берут работу из очереди,
а человек через панель только вмешивается — не обязан дёргать каждый шаг.
