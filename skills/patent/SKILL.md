# /patent — заготовка заявки

```bash
python tools/report.py patent H-XXX
```

Доступно только для статусов `confirmed` и `partial`. Для всего остального
инструмент отказывает: патентное описание без воспроизводимого эффекта —
это фантазия, которая потом бьёт по репутации.

## Структура черновика

1. Область техники и решаемая техническая задача (снижение compute cost).
2. Известный уровень техники со ссылками из `signal_chain` и чётким отличием.
3. Сущность: механизм как последовательность операций, а не как наблюдение.
4. Формула: независимый пункт + зависимые (пороги, момент измерения, агрегация).
5. Примеры реализации: конкретные seeds, шаги, числа из `summary.json`.
6. Технический результат в цифрах: сколько compute сэкономлено при какой потере качества.
7. Границы: где метод НЕ работает — обязательный раздел.

Все числа берутся из таблицы вердиктов и файлов `results/`, никогда из памяти
модели. Документ — технический черновик, НЕ юридический документ; это
прямо написано в шапке файла `reports/patent-H-XXX.md`.
