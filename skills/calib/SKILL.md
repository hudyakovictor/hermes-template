# /calib — калибровка

```bash
python tools/calib.py report      # что говорят данные
python tools/calib.py weights     # текущие веса
python tools/calib.py apply       # применить новые веса
```

## Логика

По закрытым вердиктам считается **различающая сила** каждого фактора PI: насколько
его среднее значение отличается у подтверждённых/частичных гипотез от опровергнутых.
Фактор, который ничего не различает, теряет вес; тот, который различает, приобретает.

## Защиты, которые НЕЛЬЗЯ обходить

- **Минимум 8 закрытых вердиктов.** Калибровка на 3 точках — самообман,
  инструмент откажется и это правильно.
- **Шаг не больше 20 % относительно.** Резкие прыжки весов превращают очередь
  в генератор шума.
- **Требуются оба класса исходов.** Если все гипотезы подтверждены — гейт слаб,
  а не исследователь гениален.
- Веса пишутся в базу (`pi_weights`), `config.yaml` не переписывается никогда.

## Главная метрика честности

Среднее отклонение прогноза от факта. Если оно растёт — модель мира ухудшается,
и никакое количество новых гипотез это не компенсирует. Об этом надо сказать
прямо в недельном отчёте.

Запускается cron’ом `weekly-recalib` по воскресеньям в 20:00.
