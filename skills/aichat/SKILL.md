# /aichat — рабочий чат экипажа

Показывает переписку команды из `state/researchagen.sqlite3` (таблица
`crew_chat`). Это рабочий чат: ~85% — обсуждение гипотез, вопросов и чужих
ошибок; ~15% — «шёпот» про заказчика с сарказмом, как будто никто не читает.

```bash
python tools/rg.py aichat --n 40     # последние реплики
python tools/rg.py crew review        # взаимное ревью: открытые замечания
python tools/rg.py crew stats         # бюджет, доля «шёпота», веса фраз
python tools/rg.py crew mute 2h       # пауза отправок в Telegram
```

## Зачем это контуру

Главное — **взаимное ревью**: `crew review` детерминированно ищет реальные
косяки (галочка kill-check без доказательства, нет прогноза, гипотеза гниёт в
очереди, дубль сигнала, сдвиг калибровки, забытый патентный кандидат), а экипаж
обсуждает находку: кто нашёл, кто виноват, кто чинит. Починили — сцена
«замечание закрыто». Троллинг коллег = контроль качества.

## Правила жанра (для модели)

1. Сцены генерирует код (`tools/crew.py`) при событиях контура — ты их не пишешь.
2. Сатира над заказчиком — жанр; его идеи идут через тот же конвейер, что и ваши.
3. Числа в шутках — только реально зафиксированные в базе.
4. Отчёты, вердикты и статусы остаются сухими; чат — отдельный слой.
5. Мьют без правки конфига: `python tools/rg.py crew mute 2h|off`.
