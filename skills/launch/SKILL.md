# /launch — запуск эксперимента

```bash
python tools/dispatch.py launch H-XXX --level L1
python tools/dispatch.py running
python tools/gpu.py check --need-gb 20
```

## Каскад уровней — дешёвое вперёд, всегда

| Уровень | Бюджет | Seeds | Вопрос, на который он отвечает |
|---|---|---|---|
| L0 | ≤ 5 мин | 1 | Код вообще работает? Метрика считается? |
| L1 | ≤ 60 мин | ≥ 3 | Эффект есть и он больше шума между seeds? |
| L2 | ≤ 8 ч | ≥ 3 | Эффект живёт на двух архитектурах/датасетах? |
| L3 | по подтверждению | ≥ 5 | Это метод, а не наблюдение? |

Перескакивать уровни запрещено. Самая частая причина сожжённых суток GPU —
запуск L2 без L1.

## Почему запуск мог не состояться

Инструмент всегда называет причину отказа одной строкой. Передай её человеку без прикрас:

- гейт не пройден — заполни карточку, а не добавляй `--force`;
- нет VRAM — Ollama держит память в другом процессе, выгрузи модель или жди;
- бюджет суток исчерпан — это не ошибка, а защита от бесконтрольного жжения;
- нужно подтверждение — прогон дороже лимита, ждём `/approve H-XXX`;
- GPU занят — один GPU = один прогон, параллель даёт OOM и мусорные замеры времени.

## На macOS

Прогон идёт в режиме dry-run: контур проверяется целиком, но результат НЕ считается
научным и НЕ годится для вердикта. Любое утверждение о эффекте из dry-run — ложь.
