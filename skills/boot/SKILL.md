# /boot — запуск дежурства

Вызови на первом сообщении сессии (вместо приветствия) и по командам
`/start`, `/boot`.

```bash
python tools/rg.py boot          # факты одним вызовом (--json для машины)
```

## Порядок

1. Прочитай вывод `boot`: пауза?, selfcheck (❌ → чинить сначала),
   зарегистрирован ли cron, жив ли gateway, очередь/бюджет/NEXT.
2. Автономия: `hermes cron list` должен содержать `dispatcher` (*/2 мин) и
   `research-loop` (*/25 мин). Нет — перезапусти `install.sh` (блок cron)
   или добавь задания из `cron/*.json` вручную. Управление в Telegram —
   `researchagen gateway start`.
3. Ответь человеку: цифры → ID → одно следующее действие. Одной строкой
   сверху можно поздороваться.
4. Ничего не жди: если есть NEXT и GPU свободен — диспетчер сам запустит
   (cron), тебе вручную не дублировать. Твоя первая работа — открытые
   замечания ревью и разбор inbox.

## Чего не делать

- Не отвечать «готов к задачам» — это профиль действия, а не ожидания.
- Не запускать GPU-прогоны вручную: только диспетчер (`tools/dispatch.py`).
- Не восстанавливать состояние по памяти: только `state/` и вывод CLI.
