# /digest — сводки

```bash
python tools/report.py digest --send     # сутки
python tools/report.py weekly --send     # неделя
python tools/report.py status            # текущий штаб
```

Дайджест уходит cron’ом в 09:00 в тему «Штаб». Оба пользователя видят одни и те же
цифры, потому что всё считается из одной базы, а не из истории чата.

## Что обязательно в сводке

1. Цифры: новые гипотезы, прогоны, вердикты, снятые до теста, GPU-часы.
2. Каждый вердикт — факт против прогноза и отклонение в процентах.
3. Если за сутки не случилось ничего — назвать причину (пауза / пустая очередь /
   занятая VRAM / ждёт подтверждения). Тишина без причины недопустима.
4. Калибровка: средняя ошибка прогнозов и GPU-часы на одно подтверждение.

## Чего в сводке быть не должно

Пересказа планов без цифр, оценочных слов («хороший прогресс»), извинений
и обещаний на будущее. Сводка — это бухгалтерия, а не презентация.
