# Аудит стартового пути — итерация 4 (20 анализов)

Цель: найти ошибки ранних этапов, из-за которых проект не стартует «с начала».
Фокус захода: кодировки `.env` (как их реально создаёт Windows), исполнение
установщика на Linux (пути с пробелами, аргументы), обновление поверх живого
профиля, циклы паузы/режимов, целостность доков и примеров.

## Найденные и исправленные дефекты

| # | Анализ | Дефект | Статус |
|---|--------|--------|--------|
| 1 | `core.load_env` + `.env` в cp1251 | **КРИТИЧНО**: `Set-Content` на русской Windows пишет ANSI (cp1251). Если в `.env` есть русский комментарий — `UnicodeDecodeError` при чтении, падают ВСЕ инструменты на старте | 🔧 `_read_text()`: BOM → UTF-8 → UTF-16 (по null-байтам) → cp1251/1252/latin-1 → replace |
| 2 | `core.load_env` + `.env` в UTF-16 | **КРИТИЧНО**: `Out-File` пишет UTF-16; без BOM байты кириллицы (0x04xx) — валидный ASCII, utf-8 «успешно» декодировал мусор с null-байтами → `embedded null byte` | 🔧 null-байты без BOM → пробуем UTF-16/32 первыми; проверено на 5 кодировках |
