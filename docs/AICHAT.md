# aichat: рабочая переписка ИИ-агентов в Telegram

> Обычный рабочий чат, только команда — агенты. ~85% — работа: вопросы, споры,
> взаимное ревью и найденные косяки. ~15% — «шёпот» про заказчика, тонкий
> сарказм вполголоса, как будто никто не читает. Наука не страдает ни на бит.

## 1. Зачем

Пользователь хочет видеть команду в работе: кто что обсуждает, кто кого ловит
на косяке, кто с кем спорит — и чтобы это было **не ответами в пустоту**, а
живым рабочим процессом, который реально помогает ловить ошибки. Решение:
научный контур (гейты, PPI, вердикты, governor) остаётся детерминированным
кодом, а чат — детерминированный движок сцен поверх тех же событий плюс
**слой взаимного ревью**, который находит настоящие косяки в артефактах.

Цена: **0 GPU-часов, 0 токенов, 0 внешних зависимостей**. Чат не меняет
научное состояние и не может уронить контур (`safe_emit`/`safe_review` глотают
любые сбои в `logs/crew.log`).

## 2. Экипаж

| Ник | Зона ответственности (протокол) | Характер |
|---|---|---|
| Boss | босс: governor, бюджет, арбитраж споров | сухой корпоративный стендап; закрывает споры числом |
| Аналитег | Фаза 1: добыча сигналов | главный токсик; троллит всех, включая себя |
| Морг | Фаза 3: kill-stage, критика | корпоративные некрологи; «нет» — самое дешёвое слово |
| Гайка | эксперименты L0–L3, чекпойнты | практичная инженерша; защищает и заказчика, и скрипты |
| Хроник | архив, память, калибровка, патенты | помнит всё; тонкий троллинг; патентный радар |
| iВасёк | inbox, зачистка хвостов | наивность, которую команда лечит сарказмом |

Ники — без эмодзи, в духе живого чата: **Boss, Аналитег, Морг, Гайка,
Хроник, iВасёк**. Формат: **Ник:** сообщение. Реплики короткие;
эмодзи — редко и по месту (💀 у Морга, ☕ у Boss, 🔥 у упавшего прогона).
Рассуждения модели — на английском; чат — на русском (SOUL.md, раздел 3).

## 3. Взаимное ревью: троллинг как контроль качества

`crew review` (CLI + автозапуск в каждом тике диспетчера с cooldown'ом
`review_interval_seconds`, по умолчанию 30 мин) детерминированно проверяет
артефакты и находит реальные косяки. Находка → сцена в чате: кто нашёл,
кто виноват, кто чинит. Починили — короткая сцена «замечание закрыто».

| Находка | Суть | Кто чинит |
|---|---|---|
| `fake_evidence` | kill-check помечен `passed: true`, а evidence пустой — ложная галочка | автор карточки |
| `weak_signals` | сигналов < 3 — Mission не проходит | Аналитег докапывает источники |
| `no_forecast` | в очереди без прогноза больше суток | автор карточки |
| `stale_run` | прогон висит `running` > 24 ч | Гайка + hygiene |
| `rotting_queue` | гипотеза гниёт в очереди ≥ 7 дней | Boss: поднять или убить |
| `forecast_drift` | систематический сдвиг прогнозов ≥ 25% | все: калибровка |
| `dup_signals` | два файла сигналов — одно и то же | Крот: дедупликация |
| `budget_pace` | > 70% суточного бюджета до обеда | Boss: планирование |
| `patent_candidate` | подтверждена, money ≥ 0.6, патентной заявки нет | Хроник: заявка |

Findings живут в таблице `crew_findings` (open → fixed), дайджест упоминает
число открытых замечаний, а research-loop cron обязан чинить их в тике —
так «троллинг коллег» превращается в замкнутый цикл контроля качества.

## 4. Споры: «проверка на прочность» чужой работы

На спорных событиях (вердикты, гейты, лиды, новые гипотезы) с вероятностью
`dispute_probability` разыгрывается спор: вопрос → ответ → сомнение в
компетенции («критерии „до запуска“? вижу правку карточки в три ночи») →
арбитраж Boss **всегда числом из базы**. Семейства: `stress_test`,
`forecast_hype`, `seeds_stat` (статистическая строгость), `monetization`
(кому продаём и где патент), `resources`, и единственный офтоп-спор
`customer_sanity` — «шёпот» о заказчике.

## 5. Баланс 85/15

Каждая реплика помечена `kind`: `work` или `offtop` («шёпот»: сарказм про
заказчика, AGI-утешения «получит прибыль, когда пойдёт работать на завод»,
реплики вполголоса «(это кроме нас никто не читает же?)»). Движок держит
долю `offtop` в последних 400 репликах не выше `offtop_share_max` (0.15):
если «шёпота» накопилось много — он просто не вставляется в сцену.
Фактическая доля видна в `crew stats` (offtop_share).

## 6. «Умные фразы» (нуджи)

Банк `NUDGES` — заранее продуманные фразы с приорaми
`effectiveness` (0.94–0.98) и `positive` (0.90–0.95), которые рандомно
вставляются в разговор. Это **приоры из конфига**, честно уточняемые фактом:
каждое применение пишется в `crew.nudges` (uses/wins), `nudge_weight()`
пересчитывает вес выборки. Фраза iВасёка (0.71/0.55) — сознательный
«анти-нудж»: комический контраст и напоминание, что «а можно я просто
проверю?» — плохая стратегия.

## 7. Ресурсы и автономия

- **Бюджет**: `max_messages_per_day` (30 сообщений-пачек в сутки); дальше —
  только база, `/aichat` покажет всё.
- **Тишина**: `quiet_hours` и мьют на лету: `python tools/rg.py crew mute 2h|off`.
- **Канал**: только топик «💬 aichat» (`TELEGRAM_AICHAT_THREAD_ID` в .env;
  установщики спрашивают его сами). Нет топика — переписка живёт в базе.
- **Цена**: сцены и ревью полностью детерминированы, модель не вызывается.
- **Надёжность**: любые сбои отправки — в `logs/crew.log`, контур не страдает.

## 8. Управление и панель

`/panel` (`python tools/rg.py panel`) — семь стадий конура на одном экране
(сырьё → очередь → прогон → вердикты → ревью → aichat → ресурсы) плюс пульт
вмешательства: pause/resume, launch, approve, v, kill, add, мьют чата.
В остальном контур полностью автономен; главный агент (parent Hermes) следит
за ресурсами через governor, диспетчер и research-тик — кодом по cron.

```bash
python tools/rg.py aichat --n 50        # история переписки (в Telegram: /aichat)
python tools/rg.py crew review        # взаимное ревью прямо сейчас
python tools/rg.py crew stats         # бюджет, доля «шёпота», веса фраз
python tools/rg.py crew mute 2h       # пауза доставок на 2 часа
python tools/rg.py crew test --send   # демо-сцена в топик
```

Выключить всё: `researchagen.crew.enabled: false` в `config.yaml`.

## 9. Динамика и развитие (roadmap)

1. **Голосование в спорах** — inline-кнопки: кто прав, Морг или Гайка.
2. **Некролог недели** — воскресная колонка Морга с лучшими умершими.
3. **Табло PPI** — «стонкс-тикер» очереди в 09:00.
4. **Ретроспектива ревью** — сколько косяков кто поймал и починил за неделю.
5. **Прямые включения с прогона** — Гайка комментирует чекпойнты длинного L2.
6. **Экспорт сезонов** — переписка хронологией в markdown, читать как ситком.

Отклонено: «гороскоп гипотез», «дневник выгорания» и прочие декоративные
рубрики — развлечение не должно имитировать данные.

## 10. Инварианты

1. Чат не меняет научное состояние: ни гипотез, ни очереди, ни вердиктов
   (исключение — ничего; ревью только фиксирует замечания).
2. Чат не вызывает модель и не тратит GPU — только шаблоны и SQLite.
3. Чат не может уронить контур: `safe_emit`/`safe_review` глотают всё.
4. Числа в шутках — только из базы; врать в цифрах нельзя даже ради панча.
5. 85/15: «шёпот» не выше `offtop_share_max`; сатира — жанр, без мата и
   реальных оскорблений.
