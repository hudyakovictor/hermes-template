# researchagen Mini App — пульт автономной лаборатории

Telegram Mini App для управления и наблюдения за контуром researchagen:
одним взглядом — GPU, бюджет, очередь гипотез и споры экипажа; в один тап —
пауза, одобрение дорогого прогона, снятие задачи, подача идеи.

Работает **без единой внешней зависимости**: чистые HTML/CSS/JS и
`serve.py` на Python stdlib — в духе остального репозитория.

## Быстрый старт

```bash
python3 miniapp/serve.py --port 8899
# открыть http://localhost:8899
```

Вне Telegram приложение запускается в демо-режиме: контур симулируется на
клиенте (виден бейдж «демо»). Симуляция честно повторяет механику системы:
PI/PPI по формуле из `tools/queue.py`, каскад L0–L3, kill-проверки,
рынок прогнозов экипажа, вердикты «прогноз vs факт».

## Подключение к Telegram

1. Поднимите приложение так, чтобы Telegram видел его по HTTPS:
   ```bash
   python3 miniapp/serve.py --port 8899
   cloudflared tunnel --url http://localhost:8899   # или ngrok http 8899
   ```
2. В [@BotFather](https://t.me/BotFather) того же бота, что обслуживает шлюз:
   - `/newapp` → выберите бота → имя → URL туннеля → короткое имя,
     **или** `/setmenubutton` → URL → «Web App».
3. Откройте бота → кнопка меню / команда — Mini App разворачивается на весь
   экран, подтягивает тему пользователя и хаптику.

Мини-приложение не читает сообщения бота: управление остаётся за штатным
шлюзом Hermes, Mini App — слой наблюдения и действий (см. `docs/TELEGRAM.md`,
правило «один токен — один читающий процесс»).

## Структура

```
miniapp/
  index.html          — каркас, SVG-спрайт иконок
  static/app.css      — дизайн-система «Тёмная лаборатория»
  static/core.js      — Telegram SDK, тосты, шторки, hold-to-confirm, свайпы, PTR
  static/charts.js    — графики на canvas (LineChart/Sparkline/Ring/Donut)
  static/data.js      — слой данных: живая симуляция контура + шина событий
  static/screens-a.js — Пульт, Конвейер, карточка гипотезы
  static/screens-b.js — Телеметрия, Экипаж (чат, ставки, ревью)
  static/screens-c.js — Итоги (вердикты, патенты), подача идей
  static/app.js       — запуск, маршрутизация действий, живые подписки
  serve.py            — stdlib-сервер статики + /api/ping, /api/state
```

## Мост к реальному состоянию

`serve.py` отдаёт `GET /api/state`: если рядом существует
`state/researchagen.sqlite3`, возвращает счётчики очереди/прогонов/вердиктов,
иначе `{"demo": true}`. Фронтенд обрабатывает оба случая — интерфейс не
ломается без базы. План полноценного моста (только чтение + команды через
существующие CLI-обертки `tools/rg.py`) описан в `docs/DESIGN-MINIAPP.md`.

## Экраны

| Таб | Что внутри |
|---|---|
| Пульт | VRAM-кольцо, температура, утилизация, суточный бюджет с прогнозом, текущий прогон (пауза/снятие с удержанием), подтверждение дорогих L3, лента событий |
| Конвейер | Рельс каскада L0→L3, очередь по PPI со свайп-действиями, карточка гипотезы: разбор PI по весам, коридор эффекта, 8 kill-проверок |
| Телеметрия | Живые loss-кривые по сидам, effective rank, разброс, log-шкала, наложение до 3 прогонов |
| Экипаж | Рабочий чат 7 агентов, споры с голосованием, рынок прогнозов «взлетит/не взлетит», рейтинг точности, взаимное ревью |
| Итоги | Калибровка прогнозов, «обещали vs получили», фильтры, патентные заготовки, экспорт отчётов |
| «+» | Пошаговая подача идеи: дедупликация против закрытых, симуляция PI/PPI |
